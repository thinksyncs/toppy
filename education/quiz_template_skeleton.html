Cheat Sheet (reference) チートシート（参照）
  • QUIC: UDP-based transport used by HTTP/3. QUIC: HTTP/3 が使う UDP ベースのトランスポート。
  • HTTP/3: HTTP over QUIC. HTTP/3: QUIC 上の HTTP。
  • CONNECT-UDP: HTTP/3 Extended CONNECT for UDP forwarding. CONNECT-UDP: UDP 転送用 Extended CONNECT。
  • HTTP Datagrams: carry UDP payloads in CONNECT-UDP. HTTP Datagrams: CONNECT-UDP の UDP ペイロード搬送。
  • MASQUE: proxying over QUIC/HTTP (toppy experiments with it). MASQUE: QUIC/HTTP のプロキシ仕様群（toppy が実験）。
  • Key config: `server_name` is TLS SNI. 主要設定: `server_name` は TLS SNI。

Q1: Which transport does HTTP/3 use? Q1: HTTP/3 のトランスポートはどれ？

Multiple Choice 択一
Explanation: 解説: HTTP/3 runs over QUIC. HTTP/3 は QUIC 上で動作します。

Q2: Correct term? Q2: 正しい表記は？

Multiple Choice 択一
Explanation: 解説: The correct protocol name is HTTP/3. 正しい名称は HTTP/3 です。

Q3: CONNECT-UDP is defined using which HTTP feature? Q3: CONNECT-UDP はどの HTTP 機能を使う？

Multiple Choice 択一
Explanation: 解説: CONNECT-UDP uses HTTP/3 Extended CONNECT. CONNECT-UDP は Extended CONNECT を使います。

Q4: In toppy, CONNECT-UDP forwards what? Q4: toppy の CONNECT-UDP は何を転送？

Multiple Choice 択一
Explanation: 解説: toppy uses CONNECT-UDP over HTTP/3 with HTTP Datagrams to carry UDP payloads. toppy は HTTP/3 + HTTP Datagrams 上の CONNECT-UDP で UDP を運びます。

Q5: HTTP Datagrams in toppy are used for ___. Q5: toppy の HTTP Datagrams の用途は？

Multiple Choice 択一
Explanation: 解説: HTTP Datagrams carry UDP payloads for CONNECT-UDP. HTTP Datagrams は CONNECT-UDP の UDP ペイロード搬送に使います。

Q6: What is toppy primarily for? Q6: toppy の主目的は？

Multiple Choice 択一
Explanation: 解説: toppy is a workspace for a MASQUE-capable gateway and CLI experiments. MASQUE 対応ゲートウェイと CLI の実験用ワークスペースです。

Q7: `toppy up` is currently: Q7: `toppy up` は現在どれ？

Multiple Choice 択一
Explanation: 解説: `toppy up` is a local TCP forwarder, not a MASQUE tunnel yet. 現時点ではローカル TCP フォワーダです。

Q8: Select all workspace crates. Q8: ワークスペースの構成クレートをすべて選べ

Multi-Select 複数選択
Explanation: 解説: The workspace includes CLI, gateway, core, and proto. CLI・ゲートウェイ・共通・プロトが含まれます。

Q9: Which component is the QUIC + HTTP/3 gateway? Q9: QUIC + HTTP/3 ゲートウェイは？

Multiple Choice 択一
Explanation: 解説: `toppy-gw` is the QUIC + HTTP/3 gateway. `toppy-gw` がゲートウェイです。

Q10: Default config path is: Q10: デフォルトの設定パスは？

Multiple Choice 択一
Explanation: 解説: Default config path is `~/.config/toppy/config.toml`. デフォルトは `~/.config/toppy/config.toml` です。

Q11: Which command acquires and caches tokens? Q11: トークン取得・キャッシュを行うコマンドは？

Multiple Choice 択一
Explanation: 解説: `toppy login` performs token acquisition and caching. `toppy login` がトークン取得・キャッシュです。

Q12: If no allow rules are configured, policy result is: Q12: allow ルールが無い場合のポリシーは？

Multiple Choice 択一
Explanation: 解説: No allow rules means default deny. allow ルールが無い場合はデフォルト deny です。

Q13: Correct UDP forwarding path? Q13: UDP 転送の正しい経路は？

Multiple Choice 択一
Explanation: 解説: The local app talks to the CLI, then gateway, then target, and returns back the same way. CLI→GW→ターゲット→戻りの順です。

Cheat Sheet (reference)
  • QUIC: UDP-based transport used by HTTP/3. / HTTP/3 が使う UDP ベースのトランスポート。
  • HTTP/3: HTTP over QUIC. / QUIC 上の HTTP。
  • CONNECT-UDP: HTTP/3 Extended CONNECT for UDP forwarding. / UDP 転送用 Extended CONNECT。
  • HTTP Datagrams: carry UDP payloads in CONNECT-UDP. / CONNECT-UDP の UDP ペイロード搬送。
  • MASQUE: proxying over QUIC/HTTP (toppy experiments with it). / QUIC/HTTP のプロキシ仕様群。
  • Key config: `server_name` is TLS SNI. / `server_name` は TLS SNI。

Q1: Which transport does HTTP/3 use? / HTTP/3 のトランスポートはどれ？

Multiple Choice
Explanation: HTTP/3 runs over QUIC. / HTTP/3 は QUIC 上で動作します。

Q2: Correct term? / 正しい表記は？

Multiple Choice
Explanation: The correct protocol name is HTTP/3. / 正しい名称は HTTP/3 です。

Q3: CONNECT-UDP is defined using which HTTP feature? / CONNECT-UDP はどの HTTP 機能を使う？

Multiple Choice
Explanation: CONNECT-UDP uses HTTP/3 Extended CONNECT. / CONNECT-UDP は Extended CONNECT を使います。

Q4: In toppy, CONNECT-UDP forwards what? / toppy の CONNECT-UDP は何を転送？

Multiple Choice
Explanation: toppy uses CONNECT-UDP over HTTP/3 with HTTP Datagrams to carry UDP payloads. / HTTP/3 + HTTP Datagrams で UDP を運びます。

Q5: HTTP Datagrams in toppy are used for ___. / toppy の HTTP Datagrams の用途は？

Multiple Choice
Explanation: HTTP Datagrams carry UDP payloads for CONNECT-UDP. / CONNECT-UDP の UDP ペイロード搬送に使います。

Q6: What is toppy primarily for? / toppy の主目的は？

Multiple Choice
Explanation: toppy is a workspace for a MASQUE-capable gateway and CLI experiments. / MASQUE 対応ゲートウェイと CLI の実験用ワークスペースです。

Q7: `toppy up` is currently: / `toppy up` は現在どれ？

Multiple Choice
Explanation: `toppy up` is a local TCP forwarder, not a MASQUE tunnel yet. / 現時点ではローカル TCP フォワーダです。

Q8: Select all workspace crates. / ワークスペースの構成クレートをすべて選べ

Multi-Select
Explanation: The workspace includes CLI, gateway, core, and proto. / CLI・ゲートウェイ・共通・プロトが含まれます。

Q9: Which component is the QUIC + HTTP/3 gateway? / QUIC + HTTP/3 ゲートウェイは？

Multiple Choice
Explanation: `toppy-gw` is the QUIC + HTTP/3 gateway. / `toppy-gw` がゲートウェイです。

Q10: Default config path is: / デフォルトの設定パスは？

Multiple Choice
Explanation: Default config path is `~/.config/toppy/config.toml`. / デフォルトは `~/.config/toppy/config.toml` です。

Q11: Which command acquires and caches tokens? / トークン取得・キャッシュを行うコマンドは？

Multiple Choice
Explanation: `toppy login` performs token acquisition and caching. / `toppy login` がトークン取得・キャッシュです。

Q12: If no allow rules are configured, policy result is: / allow ルールが無い場合のポリシーは？

Multiple Choice
Explanation: No allow rules means default deny. / allow ルールが無い場合はデフォルト deny です。

Q13: Correct UDP forwarding path? / UDP 転送の正しい経路は？

Multiple Choice
Explanation: The local app talks to the CLI, then gateway, then target, and returns back the same way. / CLI→GW→ターゲット→戻りの順です。

Q14: Select the CONNECT-UDP endpoints. / CONNECT-UDP のエンドポイントを選べ

Multi-Select
Explanation: Echo uses `/udp/` and forwarding uses `/udp-forward/`. / `udp` は echo、`udp-forward` は転送です。

Q15: TLS SNI config key is? / TLS SNI のキーは？

Short Text
Explanation: The key is `server_name`. / `server_name` が TLS SNI です。

Q16: Command to verify audit log? / 監査ログ検証コマンドは？

Short Text
Explanation: Use `toppy audit verify` (with optional args). / `toppy audit verify` を使います。
